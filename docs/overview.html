Every mux, and why it has the inputs it has

PC select
4:1. PC+4 for sequential flow; the jump field of the instruction in ID (J, JAL resolve in ID, no adder needed since MIPS jumps are absolute); the branch target from ID/EX (all six conditional branches resolve in EX); the forwarded rs from EX (JR, JALR). One of the four is chosen by the Next-PC logic each cycle.
ID/EX A
2:1. rs from the register file, or the write-back data when rs is the register being written this cycle (the file cannot deliver it, so it is steered from MEM/WB).
ID/EX B
4:1. rt from the register file; write-back data by the same steer; the immediate, sign- or zero-extended or shifted for LUI; the link address for JAL and JALR. While the jump is in ID the incrementer already holds PC+4 of the delay slot, which is PC+8, so the link needs no adder; the ALU passes B through and it writes back like any result.
ID/EX store data
2:1. rt from the file or steered write-back. Exists because SW needs rt as data while B carries the address offset.
Forward A, B, store data
3:1 each. The ID/EX value; the EX/MEM result when the writer is the instruction one ahead; MEM/WB data when it is two ahead. Three ahead was already handled by steer. B is also inverted here for subtraction.
MEM/WB
2:1. Load data from memory, or the ALU result, whichever this instruction produced.
Shifter
32-bit barrel shifter for SLL, SRL, SRA and their variable forms. B is the value shifted and the low five bits of A are the amount (the shamt field is steered into A for constant shifts). Two levels: rotate by the low three bits, then by multiples of eight with the mask and sign fill folded in.

Units with no mux

PC+4
13-bit incrementer on the word address.
Branch target adder
13-bit add of PC+4 and the branch offset, in ID, so the target is ready when the branch is decided in EX.
ALU
32-bit add, subtract (B inverted, carry-in 1), and, or, xor, nor, slt, sltu, and pass-B for links. The result mux beside it picks the shifter instead for shift instructions; in the chips that mux is folded into the EX/MEM register. The compare beside it decides BEQ and BNE from the same forwarded operands; BLEZ, BGTZ, BLTZ and BGEZ use the sign bit of A and the compare against r0.
Register file
Two read ports (rs, rt) and one write port. The write port's data is the write-back wire; its address and enable are a copy delayed by two delay-line taps so they hold past the clock edge that ends the write.
Instruction and data memory
Instruction memory is 32 KB of single-port SRAM and only reads. Data memory is single-port SRAM too (32 KB with AS7C164A parts at 37 ns, 128 KB with IS61C256AH parts at 34 ns), always selected. A store writes during its own MEM cycle with a pulse made from a delay-line tap gated by the store flag in one fast gate; the memory's outputs are turned off a cycle early so the store-data drivers can take the bus. A load right behind a store, or a store right behind a load, waits one cycle in ID. See docs/memory-timing.md.

Not drawn: decode, which turns the instruction into the select and enable signals that steer every unit above, and the forwarding and steer comparators that compute those selects one stage early.
