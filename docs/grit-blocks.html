Grit Block Diagram

17 GALs. Two shared buses, one transfer per clock. Blue is the data bus: an arrow toward it is a driver, away from it a latch that loads. Gold is the address bus: the PC drives it while fetching, the A latch otherwise; the three memories listen and select themselves from A15 and A14. Green is point-to-point. Each block lists the control lines it takes.

The microprogram: what is active in each state

One driver per bus per state. A load line is a clock enable on the listed latch; WR# is the state gated with the clock's low half. Chip selects come from the address, so RD# and WR# are the only memory strobes.
